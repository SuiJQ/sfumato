# 03 · 开发阶段

> 单人开发的排期假设。人日是保守估计，不含调参试错。
> 每个阶段的出口是**可演示 + 可验收**，不是"代码写完了"。

---

## 阶段总览

```
P0 脚手架 ──► P1 渲染内核+万金油 ──► P2 交互+导出 ──► P3 分析+可选项 ──► P4 风格LUT ──► P5 打磨
  0.5–1d         3–4d                 2–3d            3–4d              2–3d          2–3d
                  └──── M1 能用了 ────┘                └── M2 成立了 ──┘   └─ M3 完整 ─┘
```

**M1（P2 结束）**：能拖图进去、拉滑杆、导出。零模型、零 Worker，一个静态目录就能跑。
**M2（P3 结束）**：mask 自动生成，"不用抠图"这件事成立。这才是护城河。
**M3（P5 结束）**：风格层 + 离线包 + 性能达标。

---

## P0 · 脚手架（0.5–1 人日）

**目标**：一个能跑空壳的工程，把后面所有的坑提前踩掉。

### 任务
- [ ] Vite + 原生 JS（不引框架）
- [ ] `index.html`：全屏 canvas + 左侧面板 + 底部滑杆条
- [ ] WebGL2 能力检测，不支持则直接显示说明页（不写回退）
- [ ] `gl/context.js`：创建上下文，`preserveDrawingBuffer:false`，`antialias:false`
- [ ] 一个红色 `clearColor` 的 render 循环，确认 rAF 正常
- [ ] `docs/` 目录纳入仓库，README 索引

### 验收
- `npm run dev` 打开是红屏，控制台无警告
- `#version 300 es` 的 shader 能编译

### 风险
无。这一步唯一目的是**别在没跑通渲染管线时写业务逻辑**。

## P1 · 渲染内核 + 万金油（3–4 人日）

**目标**：一张图进去，出来就是"变干净了"。这是整个产品的地基。

### 任务

**1. 纹理与采样**
- [ ] `gl/textures.js`：`ImageBitmap → RGBA8 texture`，`generateMipmap`
- [ ] `TEXTURE_3D` 占位（33³ 白色恒等 LUT），提前验证 3D 纹理可用
- [ ] 曲线 LUT（256×1 RGBA8）生成：锚点 → 单调三次插值 → 256 采样

**2. Shader 骨架**
- [ ] `pipeline.glsl`：按 §2 顺序写满 13 个算子
- [ ] `uniform4fv(u_p[8])` 一次上传
- [ ] mip level 4 作为局部对比基准（`texture(..., u_mipLevel)`）
- [ ] `linearToSrgb` / `srgbToLinear` / `oklab` 三个工具函数
- [ ] **恒等性测试**：全部 identity 参数 → 输出与原图逐像素 `≤1/255`

**3. JS 映射层**
- [ ] `core/mapping.js`：`stats → 万金油参数`（§7 全部公式）
- [ ] `effective = identity + (target-identity) * s` 的统一收敛函数
- [ ] `s` 由噪点估计衰减（`sigma > 0.05 → 0.7`）

**4. 解码**
- [ ] `core/decode.js`：扩展名 + MIME + 魔数三重校验
- [ ] `createImageBitmap(file, {imageOrientation:'from-image', premultiplyAlpha:'none'})`
- [ ] 拒绝 >50MP；CMYK/16bit 只给提示不阻塞
- [ ] 缩略图路径：`OffscreenCanvas` 缩到长边 1024

**5. 参数校准**
- [ ] 按 §15 清单跑 20 张样张，逐项调公式

### 验收
- 20 张跨题材样张，**无一张主观变差**
- 恒等测试通过
- 1024px 预览拖动时 ≥ 55fps
- 代码量 ≤ 800 行

### 风险
| 风险 | 应对 |
|---|---|
| 万金油过猛，一眼"滤镜感" | 所有增量先取 0.6 倍，跑完样张再往上加 |
| Oklab 段出现色相跳变（近中性灰度） | 在 `|a|,|b| < 0.005` 时跳过旋转 |
| mip 模糊不够软，局部对比出块 | 先接受；真不行再上一个小高斯 pass（P3 再加） |

## P2 · 交互 + 预设 + 导出（2–3 人日）

**目标**：可用。能拖图、能调、能存、能导出。

### 任务
- [ ] 拖拽 + 文件选择 + 剪贴板粘贴
- [ ] 六根滑杆（`-100..100`），带双击归零
- [ ] 事件合并：`input` 只存最新值，rAF 里统一提交
- [ ] 长按 `\` 对比原图（临时把 `s` 置 0）
- [ ] `core/presets.js`：JSON 读写、导入导出为文件（替代"分享"）
- [ ] `core/storage.js`：IndexedDB（presets / luts / settings）
- [ ] `workers/export.js`：独立 OffscreenCanvas + WebGL2 + 同一份 GLSL
- [ ] shader 末尾白底铺平 → `convertToBlob({type:'image/jpeg', quality:0.93})`
- [ ] 导出进度提示 + 失败回退提示

### 验收
- 拖入 → 调 → 导出，全程零报错，24MP 导出 < 1.5s
- 导出时 UI 不掉帧（拖动另一个滑杆仍流畅）
- 关掉浏览器再打开，预设还在
- 导出文件用系统看图软件打开，颜色与预览一致

### 风险
| 风险 | 应对 |
|---|---|
| 预览与导出颜色不一致 | 两个上下文都强制 `alpha:false` + sRGB；用同一张测试图做像素对比 |
| JPEG 透明区变黑 | shader 里铺白，不依赖 canvas 行为 |
| 导出时显存翻倍（两份全尺寸纹理） | 导出完成后立即 `deleteTexture` + `bitmap.close()` |

## P3 · 分析 Worker + 可选项（3–4 人日）

**目标**：**"不用抠图"这件事成立。** 这是产品的分水岭。

### 任务

**1. 环境**
- [ ] 把 `ort-wasm-*` 放本地，`ort.env.wasm.wasmPaths = './ort/'`
- [ ] 离线冒烟测试：断网，确认模型能加载（防 CDN 回退）
- [ ] `models/modnet_int8.onnx` 放本地，`preload` 消息触发加载
- [ ] 首帧之后 `requestIdleCallback` 预热，不挡首屏

**2. 分析 Worker**
- [ ] 512px 缩放 → ORT 推理 → alpha
- [ ] `mask_skin = person ∩ 肤色先验(Lab)`，FaceMesh bbox 加权
- [ ] `mask_sky` 启发式：上部 + 蓝/亮 + 低纹理 → 导向滤波
- [ ] 打包成单张 RGBA8（R/G/B/A）
- [ ] 统计 `Stats`（§6 全部字段）
- [ ] `progress` 消息驱动 UI 的"分析中"

**3. 渲染侧**
- [ ] shader 加入 mask 采样 + 4 抽头联合双边上采样
- [ ] 分区增益（`satSkin/satSky/satRest`、`hueSkin/hueSky`、`lumaSkin/lumaSky`）
- [ ] 肤色归一（`skinNorm`）
- [ ] 可选项开关 UI + 规则表（§8）+ `locked` 机制
- [ ] 无 mask 时的降级路径（分析失败 → 万金油照常工作）

### 验收
- 人像图：发丝、栏杆、树叶边缘**无光晕、无硬边**
- 天空区域：增强后天空色相稳定，不出现青色块
- 人像肤色 ΔE00 中位数 < 3（对比原图）
- 分析失败时功能完整，只是没有分区效果
- 分析期间拖动滑杆不卡（Worker 隔离验证）

### 风险
| 风险 | 应对 |
|---|---|
| 单线程 WASM 推理 > 1s | 降到 384px 输入；mask 反正要上采样 |
| 发丝边缘光晕 | 提高联合双边的 σ；必要时对 mask 做 1px 腐蚀后再羽化 |
| 天空启发式在阴天/水面失效 | 失败就退化为"不增强天空"，绝不乱改 |
| Skia/纹理格式差异导致 mask 通道错位 | 传 mask 前显式 `premultiplyAlpha:'none'` + `colorSpaceConversion:'none'` |

## P4 · 风格 LUT + 从参考图学风格（2–3 人日）

**目标**：把"拟合某个博主"从核心降级成一个可选玩具。

### 任务
- [ ] `TEXTURE_3D` 33³ LUT 加载（`.cube` 解析）
- [ ] tetrahedral 插值（避免天空色带）
- [ ] `styleStrength` 滑杆接线
- [ ] "从参考图学风格"：用户给一张参考图 → 在 Worker 里解最小二乘 → 33³ LUT
  - 采样 20 万像素，在 Oklab 里拟合，迭代 2 轮 IRLS 抗异常
  - 目标耗时 < 2s，进度条
- [ ] LUT 存 IndexedDB，导出 `.cube` 文件

### 验收
- 加载 `.cube` 后风格可见，`styleStrength=0` 严格无效果
- 学出来的 LUT 套到其他图上"味道对"，不出现色块/色带
- LUT 拟合失败（参考图过小/过灰）有明确提示

### 风险
| 风险 | 应对 |
|---|---|
| 参考图与被处理图内容差异大 → 过拟合 | 只用色度统计拟合，不用逐像素；加正则项拉向恒等 |
| 33³ 在强对比处出色带 | tetrahedral 是必须的，不是可选 |
| 用户以为这是"AI 换风格" | UI 文案写清"只学色调，不学内容" |

## P5 · 打磨（2–3 人日）

**目标**：从"能跑"到"天天想用"。

### 任务
- [ ] 守门员（§13）：四个指标 + 自动回退
- [ ] 快捷键：`[` `]` 切图，`Ctrl+Z` 撤销，`Ctrl+S` 导出
- [ ] 批量：多选导入，套同一预设顺序处理（**串行**，一次一张，避免显存爆）
- [ ] 空状态、加载态、错误态三套 UI 文案
- [ ] Tauri v2 打包，注入 COOP/COEP，验证多线程 WASM 生效
- [ ] 离线验证：拔网线全流程走通
- [ ] 性能采样：导出 20 张，记录耗时分布，定位长尾
- [ ] 显存泄漏检查：连续切 50 张图，`performance.memory` 不持续上涨

### 验收
- 连续处理 50 张图不崩、不卡、不涨内存
- Tauri 包里 `SharedArrayBuffer` 可用（`crossOriginIsolated === true`）
- 深色模式、1x/2x 屏都正常
- 冷启动到可交互 < 1s

## 依赖关系

```
decode ──┬─► textures ──► pipeline.glsl ──► mapping ──► 滑杆 UI
         │                                        │
         └─► thumbnail                            ▼
                                          guard ──► export worker
analyze worker ──► mask texture ─────────────┘
        ▲
   models + ort（本地）
```

**关键路径是 `pipeline.glsl`**。它一旦稳定，其余都是外围接线；它不稳定，所有调参都是白做。

---

## 建议的开发顺序（如果你只有周末）

1. **第一天**：P0 + 纹理上传 + 恒等 shader（能原样显示一张图）
2. **第二天**：曲线 + 白平衡 + 曝光 + rolloff（万金油的一半，已经能看出效果）
3. **第三天**：Oklab 饱和度 + 局部对比 + 锐化（万金油成立）
4. **第四天**：六滑杆 + 导出（M1 达成）

到这一步，你已经有一个能天天用的东西。P3 之后再谈"不用抠图"。
