# 02 · 算子与参数规格

> ## ⚠️ 实现差异（v0.2 落地后修订，**以本节为准**）
>
> 规格写于编码前，落地时为了正确性与性能做了以下修改，本文其余部分保留为设计意图：
>
> 1. **色调曲线工作在 sRGB 编码域**，不是线性域。曲线纹理为 `RGBA16F`（8bit 会在暗部放大误差），
>    采样必须按纹素中心：`u = (L*255 + 0.5) / 256`。否则暗部会被夹成 0（实测恒等误差 max=7）。
> 2. **去掉 `whitePoint` / `blackPoint`**。高光柔化直接作用在编码域，曲线负责把 p01/p50/p99 对齐。
> 3. **uniform 布局改版**（`u_p[8]`，32 floats）：
>
>    | 索引 | .x | .y | .z | .w |
>    |---|---|---|---|---|
>    | 0 | ev | temp | tint | s |
>    | 1 | knee | shadowLift | lcGain | mipLevel |
>    | 2 | sat | satSkin | satSky | satGreen |
>    | 3 | satRest | hueSkin | hueSky | hueGreen |
>    | 4 | lumaSkin | lumaSky | lumaGreen | sharpenAmt |
>    | 5 | sharpenLimit | grainAmt | grainSize | vignetteAmt |
>    | 6 | vignetteRadius | vignetteSoftness | styleStrength | skinNormStrength |
>    | 7 | skinTargetHue | skinTargetSat | faceLumaBoost | — |
>
> 4. **实际算子顺序**：线性 WB/EV → 编码 → 高光柔化 → 亮度曲线 → 阴影抬升 →
>    局部对比（取原图 mip）→ 锐化（mip1）→ 解码 → Oklab 色度 → 编码 → 3D LUT → 颗粒/暗角/抖动。
>    （规格里"局部对比在 Oklab 之后"的顺序被调换：细节只取亮度，先做更省一次往返。）
> 5. **局部对比的 mip 由原图尺寸决定**（`mipLevelFor`），不随预览分辨率变化——保证预览与导出一致。
> 6. **mask 第 4 通道是绿植**（不是预留），且必须用**裸 RGBA8 字节**上传。
>    `ImageBitmap` 会按预乘 alpha 处理，A 通道为 0 时会把整张 mask 抹平（已踩过）。
> 7. **3D LUT 用 `texelFetch` 取格点**。纹理过滤的坐标约定会让 `u = i/32` 落在格点之间。
> 8. **模块去掉 `bokeh`**（未实现就不给开关）。
>    FaceMesh 已接入（MediaPipe FaceLandmarker，CPU）：在主线程跑、按 3 段多尺度检测
>    （整图 → 中心 64% → 中心 40%），解决"全身照里的小脸漏检"。
>    脸廓用于给肤色权重加权，眼睛多边形单独栅格化成第二张 mask（`u_mask2`，R 通道），
>    峰值归一化后由 `u_p[7].w`（`lumaEye`）控制眼神光。肤色归一目标色相固定 0.85 rad。
> 9. **导出只有 JPEG q=0.93**，白底合成在 shader 末尾完成（Canvas 编码会把透明变黑）。
> 10. **守门员**：判定在 `src/core/guard.ts`（四项指标，回退系数 0.7，**最多一次**），
>     渲染与统计在 `src/workers/guard.worker.ts` —— 主线程不做 `readPixels`（实测阻塞从 206ms → 20ms 帧间隔）。
>     基线也由同一个 Worker、同一条渲染路径产出，避免两套数字对不上。
>
> ### v0.3 审查后修订
>
> 11. **统计跳过透明像素**（`a < 8`），且裁切口径统一为"三通道同时到顶/到底"。
> 12. **曲线锚点按 EV 折算**：曲线作用在加完曝光之后，锚点必须先 warp 到同一坐标系，
>     否则中灰会被"曝光 + 曲线"各对齐一次（p50=0.25 会被推到 ≈0.55）。
> 13. **回退不插值 knee**：IDENTITY 的 knee=1 表示"不做高光柔化"，若跟着回退一起插值，
>     降强度反而让高光切得更狠。
> 14. **风格迁移的色度偏移按原像素色度加权**，并改用软膝限制上限 —— 否则中性灰会被推出色相、
>     纯红（chroma≈0.26）会被硬裁到 0.18。
> 15. **噪点估计改 4 邻域 + 原始分辨率中心裁切**（缩略图插值会抹平高频噪声）。

> 本文是可执行的规格。实现时以本文为准，冲突时改本文、不改代码。
> 所有数值都是初值，需要用实拍样张校准。

## 1. 色彩空间约定

| 环节 | 空间 | 说明 |
|---|---|---|
| 纹理存储 | `RGBA8`（sRGB 编码值） | 上传时不做线性化，在 shader 里转 |
| 运算 | `linear-sRGB`（float32） | 白平衡、曝光、rolloff、曲线、局部对比、锐化 |
| 色度运算 | `Oklab` | 饱和度、色相、肤色归一 |
| 输出 | `sRGB`（gamma 编码） | 3D LUT / 颗粒 / 暗角 / 抖动都在这一域 |
| 工作帧缓冲 | `RGBA16F` | 中间精度，避免线性域 8bit 色带 |

**编码/解码函数必须成对出现，且只写一份**：

```glsl
vec3 srgbToLinear(vec3 c) { return mix(c/12.92, pow((c+0.055)/1.055, vec3(2.4)), step(0.04045, c)); }
vec3 linearToSrgb(vec3 c) { return mix(c*12.92, 1.055*pow(c, vec3(1.0/2.4))-0.055, step(0.0031308, c)); }
```

Oklab 转换用标准三矩阵 + `cbrt`，不复用外部库。

## 2. 算子表

`identity` 列表示该参数取什么值时算子严格等于恒等。**JS 映射层保证 `s=0` 时所有参数等于 identity**。

| # | id | 域 | 作用 | identity |
|---|---|---|---|---|
| 1 | `wbExposure` | linear | 通道增益 + 曝光 | `temp=tint=ev=0` |
| 2 | `rolloff` | linear | 高光软压缩 | `knee=1` |
| 3 | `toneCurve` | linear | 亮度曲线（保色相） | LUT 为恒等曲线 |
| 4 | `shadowLift` | linear | 暗部抬升 | `lift=0` |
| 5 | `chroma` | Oklab | 全局 + 分区饱和度 | `sat*=1` |
| 6 | `skinNorm` | Oklab | 肤色向目标收敛 | `strength=0` |
| 7 | `hueShift` | Oklab | 分区色相旋转 | `hue*=0` |
| 8 | `localContrast` | linear | 亮度细节增强（抑制光晕） | `gain=0` |
| 9 | `sharpen` | linear | 限幅锐化 | `amt=0` |
| 10 | `styleLUT` | encoded | 3D LUT（P3） | `strength=0` |
| 11 | `grain` | encoded | 颗粒 | `amt=0` |
| 12 | `vignette` | encoded | 暗角 | `amt=0` |
| 13 | `dither` | encoded | ±0.5LSB 抖动 | 恒开 |

### 2.1 数学定义

**1. wbExposure（linear）**
```
rgb *= vec3(1.0 + 0.30*temp + 0.05*tint,
            1.0             - 0.10*tint,
            1.0 - 0.30*temp + 0.05*tint);
rgb *= exp2(ev);
```
近似模型即可，不做严格 CCT 换算。

**2. rolloff（linear）**
```
k = clamp(knee, 0.3, 1.0);
x < k ? x : k + (1.0 - k) * (1.0 - exp(-(x - k) / (1.0 - k)));
```
输入先除以 `whitePoint` 归一，输出乘回。

**3. toneCurve（linear，只作用亮度）**
```
L   = dot(rgb, vec3(0.2126, 0.7152, 0.0722));
L2  = texture(u_curveLUT, vec2(clamp(L/whitePoint,0.,1.), 0.5)).a;   // A 通道 = 亮度曲线
rgb *= (L > 1e-5) ? (L2 / L) : 1.0;
```
**不做逐通道曲线**——逐通道会改色相（暗部偏绿就是这么来的）。

**4. shadowLift（linear）**
```
L2 = L + lift * pow(1.0 - L, 2.0);
rgb *= L2 / max(L, 1e-5);
```

**5-7. Oklab 段**
```
lab = linearToOklab(rgb);
w   = maskWeights;                      // 见 §5，和为 1
sat = u_sat * (1.0 + w.g*(satSkin-1.0) + w.b*(satSky-1.0) + w.r*(satRest-1.0));
lab.yz *= sat;                                     // a,b 同乘 → 饱和
lab.yz = rotate(lab.yz, hueSkin*w.g + hueSky*w.b);
// 肤色归一：只动色相角，不动亮度
h    = atan2(lab.z, lab.y);
h    = mix(h, skinTargetHue, w.g * skinNormStrength);
lab.yz = length(lab.yz) * vec2(cos(h), sin(h));
// 明度增益
lab.x += lumaSkin*w.g + lumaSky*w.b;
rgb = oklabToLinear(lab);
```
`w` 的推导：`w.g = m.g*(1-m.b)`、`w.b = m.b*(1-m.g)`、`w.r = clamp(1-m.g-m.b, 0, 1)`；`m.a` 预留给 P3 的主体权重。

**8. localContrast（linear）**
```
blurL = dot(texture(u_tex, uv, u_mipLevel).rgb, LUMA);
detail = (L - blurL) * u_lcGain;
guard  = smoothstep(0.02,0.15,L) * (1.0 - smoothstep(0.85,1.0,L));   // 暗部高光不加强
rgb *= (L + detail*guard) / max(L, 1e-5);
```

**9. sharpen（linear，限幅）**
```
d = clamp(L - blurSmall, -u_sharpenLimit, u_sharpenLimit);
rgb *= (L + d*u_sharpenAmt) / max(L, 1e-5);
```
限幅是关键——不限幅就会出现白边。

**10. styleLUT（encoded）**
```
c  = linearToSrgb(rgb);
c2 = tetrahedral(u_lut3D, c);
rgb = srgbToLinear(mix(c, c2, u_styleStrength));
```
用 tetrahedral 而不是三线性插值：三线性在强色域压缩处会出色带，天空最先暴露。

**11. grain（encoded）**
```
n = hash3(uv * u_grainSize + frameSeed) - 0.5;
c += n * u_grainAmt * (1.0 - smoothstep(0.8, 1.0, luma(c)));   // 高光少给
```

**12. vignette（encoded）**
```
r = length((uv - 0.5) * vec2(aspect, 1.0));
v = 1.0 - u_vigAmt * smoothstep(u_vigRadius, u_vigRadius + u_vigSoftness, r);
c *= v;
```

**13. dither（encoded）**
```
c += (hash3(gl_FragCoord.xy) - 0.5) / 255.0;
```

## 3. Uniform 布局

只用一个参数块，一次 `uniform4fv` 上传 32 个 float：

```glsl
uniform vec4 u_p[8];
```

| 索引 | .x | .y | .z | .w |
|---|---|---|---|---|
| `u_p[0]` | `ev` | `temp` | `tint` | `s`（全局强度） |
| `u_p[1]` | `knee` | `whitePoint` | `blackPoint` | `shadowLift` |
| `u_p[2]` | `sat` | `satSkin` | `satSky` | `satRest` |
| `u_p[3]` | `hueSkin` | `hueSky` | `lumaSkin` | `lumaSky` |
| `u_p[4]` | `lcGain` | `lcThreshold` | `mipLevel` | `sharpenAmt` |
| `u_p[5]` | `sharpenLimit` | `grainAmt` | `grainSize` | `vignetteAmt` |
| `u_p[6]` | `vignetteRadius` | `vignetteSoftness` | `styleStrength` | `skinNormStrength` |
| `u_p[7]` | `skinTargetHue` | `skinTargetSat` | `faceLumaBoost` | `_reserved` |

采样器：`u_tex`（RGBA8 + mipmap）、`u_mask`（RGBA8）、`u_curveLUT`（RGBA8, 256×1）、`u_lut3D`（RGBA8, 33³）、`u_noise`（可选，否则用 hash）。

**关键约定：shader 里没有 amount，也没有 identity 判断。** 所有"强度语义"在 JS 映射层完成：

```
effective = identity + (target - identity) * s * moduleAmount * sliderAmount
```

好处：GLSL 全是无分支数学；恒等性由构造保证；单测可以做逐像素恒等验证。

## 4. 曲线 LUT 规格

- 尺寸 `256 × 1`，`RGBA8`
- `R/G/B` 三通道：预留给 P3 的通道曲线（P1/P2 恒等）
- `A` 通道：亮度主曲线（**当前唯一使用的通道**）
- 生成方式在 CPU：给定 3 个锚点，解单调三次插值，采样 256 点

锚点规则：

```
p01 → 0.02
p50 → 0.50
p99 → 0.97
```

`p01/p50/p99` 来自分析阶段的亮度直方图，并做 clamp：

```
p01 ∈ [0.00, 0.15]
p50 ∈ [0.30, 0.70]
p99 ∈ [0.75, 0.99]
```

clamp 是"万金油不翻车"的核心机制，别省。

---

## 5. Mask 纹理规格

- 尺寸：长边 512，保持原图比例，`RGBA8`
- 通道：

| 通道 | 内容 | 来源 |
|---|---|---|
| R | 人像 alpha | MODNet int8（必要时 MediaPipe selfie_seg 兜底） |
| G | 皮肤 | `R ∩ 肤色先验(Lab)`，再用 FaceMesh bbox 加权 |
| B | 天空 | 启发式：上部区域 + 蓝/亮 + 低纹理，再加导向滤波 |
| A | 预留 | 255 |

**天空不上模型**。启发式 + 导向滤波在这个用途上足够，且省 6MB 模型和 200ms。

### 联合双边上采样（shader 内）

mask 分辨率只有原图的 1/6，直接双线性会产生光晕。在 shader 里做 4 抽头联合双边：

```
对 uv 所在 mask texel 的 4 个邻居：
  w_i = exp(-(L(uv_i) - L(uv))² / (2 * 0.1²))     // 以原图亮度为引导
mask = Σ w_i * m_i / Σ w_i
```

代价是 4 次额外纹理采样，换来"头发丝不发光"。

## 6. 分析输出：Stats

```ts
type Stats = {
  luma:    { p01: number; p50: number; p99: number; mean: number };
  chroma:  { meanA: number; meanB: number; satP50: number; satP95: number };
  noise:   { sigma: number };              // 高频残差标准差
  regions: { sky: number; person: number; skin: number; green: number };  // 面积比 0..1
  face:    { count: number; box: [number,number,number,number] | null; eyeLuma: number };
  clip:    { hi: number; lo: number };     // 裁切像素占比
  skinHue: number;                         // 皮肤区域平均色相角（弧度）
  skinSat: number;
};
```

全部来源都是 512px 缩略图上的统计，成本 `< 5ms`（不含模型推理）。

## 7. 万金油默认值

由 `stats` 推导，**不是常数**：

| 参数 | 公式 | 说明 |
|---|---|---|
| `ev` | `clamp(log2(0.5/max(p50,0.05)), -1.2, 1.2) * 0.7` | 对齐中灰 |
| `temp` | `-0.35 * (meanB/0.15)` clamp 到 ±0.25 | 灰世界，弱化 35% |
| `tint` | `-0.3 * (meanA/0.15)` clamp 到 ±0.2 | 同上 |
| `knee` | `clamp(0.72 + (0.2 - clip.hi*2), 0.55, 0.92)` | 逆光更强 |
| `whitePoint` | `max(p99 * 1.05, 0.9)` | |
| `shadowLift` | `0.02 + 0.06 * clamp(0.2 - p01, 0, 0.2)` | |
| 曲线锚点 | 见 §4 | |
| `sat` | `1.08` | 轻微 |
| `lcGain` | `0.28 * clamp(1 - sigma/0.06, 0.2, 1.0)` | 噪点重就少给 |
| `sharpenAmt` | `0.35 * clamp(1 - sigma/0.08, 0.2, 1.0)` | |
| `sharpenLimit` | `0.06` | |
| `grainAmt` | `0` | 万金油不开 |
| `vignetteAmt` | `0` | 万金油不开 |
| `skinNormStrength` | `0.6` | 有人像才生效 |
| `s` | `sigma > 0.05 ? 0.7 : 1.0` | 质量差自动收手 |

## 8. 可选项与默认决策规则

**用规则表，不用模型。** 可读、可调、不抖、零推理成本。

| 模块 | 默认 | 规则 |
|---|---|---|
| `portrait` | 自动 | `face.count > 0` |
| `sky` | 自动 | `regions.sky > 0.08` |
| `foliage` | 自动 | `regions.green > 0.10` |
| `dehaze` | 自动 | `(p99 - p01) < 0.65` |
| `night` | 自动 | `p50 < 0.35 && clip.hi < 0.005` |
| `film` | **关** | 永不自动开启 |
| `bokeh` | **关** | 永不自动开启；人像时给一条提示 |

用户手动改过之后，该模块进入"锁定"状态，不再被规则改写（记在 `preset.locked[]`）。

## 9. 六根滑杆的映射

输入 `v ∈ [-100, 100]`，`t = v/100`。所有增量都乘以 `s`。

| 滑杆 | 影响 |
|---|---|
| 亮 `bright` | `ev += 0.35t`；`shadowLift += 0.04t` |
| 暖 `warm` | `temp += 0.15t`；`satSkin += 0.05t` |
| 浓 `rich` | `sat *= 1 + 0.25t`；`lcGain += 0.15t`；`hueSky += 0.035t`（≈2°） |
| 净 `clean` | `lcGain -= 0.12t`；暗部色度降噪 `sat *= 1 - 0.10t*(1-L)`；曲线暗端拉直 |
| 软 `soft` | `knee -= 0.15t`；`sharpenAmt -= 0.20t`；`lcGain -= 0.15t` |
| 风格 `style` | `styleStrength += t`（无 LUT 时无效，UI 置灰） |

设计原则：**一个滑杆动一组参数，但用户只需要理解一个词。**

## 10. 预设 schema

只存"意图"，不存快照。这样万金油升级后预设依然成立。

```json
{
  "v": 1,
  "name": "日常",
  "auto": true,
  "modules": {
    "portrait": true, "sky": true, "foliage": true,
    "dehaze": false, "film": false, "night": false, "bokeh": false
  },
  "locked": ["portrait"],
  "sliders": { "bright": 0, "warm": 0, "rich": 0, "clean": 0, "soft": 0, "style": 0 },
  "lut": null
}
```

- `auto: true` → 未锁定的模块按 §8 规则表实时决定
- `locked` → 用户手动改过的模块
- `lut` → IndexedDB 里的 LUT id，或 `null`
- 体积约 400 字节；LUT 单独存（143KB）

存储：

```
IndexedDB
 ├─ presets  {id, name, json}
 ├─ luts     {id, name, blob(143KB)}
 └─ settings {theme, lastPreset, workingSpace}
```

## 11. Worker 消息协议

```ts
// shared/protocol.js
type MainToAnalyze =
  | { t: 'preload' }
  | { t: 'analyze'; id: number; bmp: ImageBitmap };      // transfer: [bmp]

type AnalyzeToMain =
  | { t: 'ready' }
  | { t: 'progress'; id: number; stage: 'seg'|'smooth'; p: number }
  | { t: 'done'; id: number; mask: ImageBitmap; stats: Stats };  // transfer: [mask]

type MainToExport =
  | { t: 'render'; bmp: ImageBitmap; params: Float32Array; mask: ImageBitmap
      curve: Uint8Array; lut: Uint8Array | null; size: [number, number] };

type ExportToMain =
  | { t: 'done'; blob: Blob }
  | { t: 'error'; message: string };
```

规则：
- `ImageBitmap` 一律 transfer，不复制
- 两个 Worker 都常驻/复用，不要每次 new
- 主线程只保留一个 `id`，过期结果直接丢弃

## 12. 导出规格

| 项 | 值 |
|---|---|
| 尺寸 | 原图像素，不缩放 |
| 格式 | JPEG（唯一） |
| 质量 | `0.93`（`convertToBlob({type:'image/jpeg', quality:0.93})`） |
| 色彩 | sRGB，不嵌入 ICC（业界默认按 sRGB 解释） |
| Alpha | 白底铺平：`rgb = rgb*a + (1.0-a)`，在 shader 末尾做 |
| 文件名 | `<原名>_grain.jpg` |
| 元数据 | 不保留 EXIF（避免方向/色彩空间二次歧义） |

**注意**：Canvas 编码 JPEG 时透明像素会变黑。必须在 shader 里显式铺白，不能指望浏览器。

## 13. 守门员（Guard）

出图后用 512px 缩略图算四个指标，全部是规则不是模型，`< 5ms`：

| 指标 | 越界条件 | 含义 |
|---|---|---|
| `contrast = p99 - p01` | 比原图下降 > 15% | 修完更灰 |
| `clip.hi` | 上升 > 0.3% | 高光被切 |
| `clip.lo` | 上升 > 0.5% | 暗部死黑 |
| `noise.sigma` | 上升 > 20% | 修完更脏 |

任一越界 → `s *= 0.7` 重算，最多回退 2 次。仍越界则输出原图并提示"这张建议手动调"。
